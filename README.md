# Practi

## Descripción

Este repositorio contiene ejercicios y prácticas de desarrollo web realizados durante mi proceso de aprendizaje.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Contenido

En este repositorio se encuentran diferentes ejercicios prácticos para aprender y mejorar mis habilidades en desarrollo web.

## Cómo ejecutar el proyecto

1. Clona este repositorio:

   ```bash
   git clone https://github.com/Andresflorezdev/Practi.git
   ```

2. Entra en la carpeta del proyecto:

   ```bash
   cd Practi
   ```

3. Abre los archivos HTML en tu navegador o utiliza la extensión Live Server de Visual Studio Code.
